# 礼乐学堂主亭

`e554ccfa-pavilion.glb` 来自用户提供的 `e554ccfa_2k.fbx` 及同名配套贴图，保留原亭子的造型、UV、栏杆和台阶。

- Blender 5.2：三角面从 896,001 减至 161,280（18%），未重新建模；随后按需求移除中央石桌和四个石凳，共 1,242 三角面，当前保留 160,038 三角面。
- 10 组 PBR 材质；30 张 JPEG 贴图全部内嵌。颜色贴图 1024px，法线及金属/粗糙度贴图 512px。
- 红漆调为低饱和暖木，瓦面调为青灰；粗糙度约 0.80–0.94，金属度约 0.015–0.04，法线强度 0.3。
- 不依赖外部纹理、Draco 或 Meshopt 解码器；使用标准 glTF PBR 与 `KHR_materials_specular`。
- glTF Y-up。源亭内地坪高度约 0.48；场景采用 `[1.16, 1, 1.16]` 缩放，较上一版宽深增加约 20%，下移台基使地坪对齐 y=0.02。
- 席间移除几案与杯具，仅保留围绕原石桌区域左右排列的四个坐垫。人物统一缩至 82%；坐垫、人物入席位置及交互提示共用席位坐标，座次和判断规则保持不变。

场景引用位置：`src/app/journey/li/liHostVisuals.tsx` 的 `ImportedPavilion`。游戏逻辑和 UI 仍由原组件管理。

## 两侧古树

`ancient-tree-left.glb` 和 `ancient-tree-right.glb` 使用用户指定的两份同名 `e554ccfa_2k.glb` 中的 TreeGen 网格。

- 左树使用 D:/Bl 版本的树干与树冠，共 18,024 三角面。
- 右树使用 Downloads 版本的细叶树冠与藤蔓，并复用左文件的树干和主树冠补齐缺失部件，共 21,985 三角面。没有重新建模，也没有使用 tree_gn.glb。
- 各部件恢复共同的局部坐标与 Y-up 节点变换，修复原文件中树干/树冠变换不一致导致的错位。
- 颜色贴图缩至最多 1024px，法线/粗糙度贴图最多 512px；贴图内嵌，叶片保留透明通道并用 alpha test 绘制，避免透明排序问题。
- 等比尺寸和左右朝向由 `ImportedAncientTree` 控制。两棵树最低根部下沉到 y=-0.4，隐藏裸露根爪；移除两侧残留的旧造型松树。外围树木、亭子和牌匾均沿用原场景。

## 压缩版本（2026-11）

三个 GLB 已用 `@gltf-transform/cli optimize` 处理：几何 Meshopt 压缩 + 30 张内嵌贴图转 WebP，
未做几何简化。运行时由 `useGLTF(url, false, true)` 启用 drei 内置的 MeshoptDecoder（本地打包，无 CDN 依赖），
WebP 解码为浏览器原生能力。体积：亭 11.34→3.82MB、右树 7.27→1.12MB、左树 4.04→0.69MB（合计 22.7→5.6MB）。
