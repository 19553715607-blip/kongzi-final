检查日期：2026-10-13。范围：当前本地项目，Next.js 前端、FastAPI 后端、随项目附带的 SQLite、Docker 配置及页面导航清单。

## 结论

主要页面基本齐全，但当前版本存在可以取得管理员权限的漏洞，暂不适合直接公开部署。需要优先修复身份与权限，再解决构建失败和功能缺口。

- 共发现 **39 个页面路由**：用户端 27 个、管理端 12 个；包括案例详情、六艺、书艺的组字/临写/毛笔 3D 子页面。
- 固定字符串形式的站内导航链接均有对应页面文件，未发现这类链接指向不存在的页面。
- 后端静态解析得到 159 条路由；Python 文件均能完成语法解析。
- TypeScript 检查通过；`npm run build` 失败，原因是 **15 处 ESLint 错误**。
- 隔离接口验证确认管理员提权、默认密钥伪造登录、他人评论删除、未发布内容读取等问题。

这里的“页面齐全”是路由与源码检查结论，不等于全部页面已经完成浏览器点击验收。

### 建议修复方式

1. **身份权限**：生产启动必须要求随机强 JWT 密钥；轮换现有密钥使旧 token 失效。注册与升级固定为普通用户；管理员由已认证管理员或部署初始化流程授予。邮箱统一规范化、设置规范化后的唯一约束；邮箱验证不能直接作为管理权限来源。
2. **评论与封禁**：游客也使用服务端签发的身份凭证；删除只以已认证主体判定归属；公开列表不要返回可用于授权的访客标识。可选鉴权复用封禁检查。评论按主体/IP 频控，赞和举报设置唯一约束。
3. **发布与机构**：公共接口固定读取已发布且父级可见的内容；未发布查询放到管理员接口。撤下内容也要从检索/向量库中清除。公开申请不能接收审批与配额控制字段。
4. **数据与资源**：账号删除采用明确的删除或匿名化策略，并覆盖所有关联记录；模型接口增加长度、并发、频率和预算限制；CSV 对公式前缀做转义；游戏提交增加过程验证与幂等约束。

### 建议增加的账号及通用界面

- **忘记密码/重置密码**：前后端均未发现相关流程，注册用户丢失密码无法自助恢复。
- **邮箱验证/变更邮箱、修改密码**：目前缺少接口与界面。
- **隐私说明与用户协议**：当前 `/terms` 是儒家术语索引，并不是用户协议；项目已有 IP、访问轨迹等采集，应有可访问的说明入口。
- **业务错误、空状态及重试**：没有自定义 `error.tsx/not-found.tsx`；Next.js 有默认处理，但个人中心/课堂等页面还需要正确的请求失败反馈。

独立 `/register` 页面并非必需：已有 `/me` 中的游客绑定邮箱注册流程，不应误判为完全没有注册功能。六艺九个相关子路由、案例详情和管理端页面均存在，也不建议为了数量重复造页面。

### 本地数据与配置不足

- 随项目附带的 `backend/kongzi.db` 中 `dialog_cases=0`、`contributions=0`。案例库没有可浏览的实际案例，导航清单里的 `/cases/1` 在这份数据中不会有对应内容。服务器数据库可能不同。
- 本地 `.env` 设置了 `LLM_PROVIDER=qwen`，但没有可用模型 API Key；`services/llm.py:124` 会回落 MockLLM。这份本地配置不能证明真实模型已经接通。
- 本地与 Compose 的 Neo4j 配置仍有默认密码，7474/7687 端口公开映射。实际对外可达性取决于服务器防火墙；上线前应配置独立密码与访问范围。
- 当前目录没有 `.git`，无法核对提交历史、实际跟踪文件和未提交差异；不能据此判断密钥是否曾被提交。

### 部署配置

`docker-compose.yml` 在容器运行阶段设置 `NEXT_PUBLIC_API_BASE`，但 `frontend/Dockerfile` 构建阶段没有接收这个变量。浏览器端 `NEXT_PUBLIC_*` 通常在 Next 构建时注入，运行时设置不能可靠改变已经生成的浏览器代码。`frontend/src/lib/apiBase.ts` 的兜底是当前域名的 8000 端口，反向代理/HTTPS 部署可能因此请求错误端口。

建议使用同源 `/api` 代理，或明确通过 Docker build args 注入浏览器配置，并验证真实访问域名下的 API 请求。

## 四、已有的有效保护

- 22 个不含路径参数的管理 GET 接口，在匿名隔离检查中均返回 401。主要问题在身份签发，不能因此认为这些接口本身没有鉴权。
- 密码已有随机盐 PBKDF2 哈希，token 签名比较使用 `hmac.compare_digest`。
- 大部分数据库业务查询使用 SQLAlchemy 参数表达式；没有发现基于这些已检查输入的直接 SQL 拼接注入。
- SVG/HTML 嵌入对经典文本使用 `html.escape`；不能将所有动态文本都笼统判断成 XSS。
- 注册/登录/游客升级、收藏、六艺、评论、管理端等并非只有页面外壳，已有对应接口和业务代码。

## 六、检查方法与边界

- 读取源码、导航文档、配置和只读数据库统计；不输出真实环境密钥、用户明细或数据库内容。
- 安装前端锁定依赖执行构建/类型检查/lint，查询 npm 官方安全数据库与 OSV。
