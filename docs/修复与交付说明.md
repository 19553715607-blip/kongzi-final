# 安全修复与交付说明

日期：2026-10-18

## 已修复

- JWT 不再有默认签名密钥；应用启动及签发 token 时要求配置至少 32 字符的 `JWT_SECRET`。
- 注册与游客升级一律创建普通账号；登录不再从邮箱白名单恢复管理员角色。首次管理员需由服务器运维命令授予权限。
- 账号邮箱在注册/登录/升级时规范化为小写，并验证基本邮箱格式；新注册及游客升级密码要求 10–128 字符，登录兼容已有账号原密码。
- 公开评论不再泄露访客编号或用户 ID。评论软删除只允许评论所属的已认证账号，匿名访客不能凭可伪造的访客编号删除内容；被封账号不能通过可选鉴权绕过评论接口限制。
- 机构申请固定为待审批状态及服务端配额，不再接受客户端自动审批或配额字段。
- 公共经典、检索、概念、Feed 和案例接口过滤未发布内容；未发布案例详情返回 404。
- 对话请求增加消息长度上限、按来源地址的短时频控，错误响应不再回传内部异常文本。
- 不再信任客户端直接提供的 `X-Forwarded-For` 来推断 IP/国家。需要代理地址时应在部署层配置可信代理。
- 管理员 CSV 导出对电子表格公式前缀转义；审计日志响应字段与管理界面预期兼容。
- 公告可在前台读取并按语言回退；案例页传入语言并显示失败状态；课堂轮播使用当前语言并提供错误重试。
- Neo4j 默认密码移除，容器端口仅绑定本机，启动要求单独配置密码。
- 升级 Next.js 与配套 ESLint 配置至 15.5.28；五个 WebGL 子页面调整为客户端入口，以符合 Next 15 约束。
- 移除 React 水合前改写 `<html>` 属性、导致语言/主题属性不匹配的内联脚本；改为客户端挂载后同步语言、主题和页面元信息。君子路「执礼」3D 场景升级至 React 19、React Three Fiber 9 与 Drei 10 的兼容组合，并调整出生点及跟随镜头，避免进院后被门楼横梁遮挡。
- 登录页安全保留同源的管理后台返回路径；无管理员权限时提供切换账号入口，后端管理员授权仍只通过运维命令执行。
- 管理员冒烟脚本不再内置可复用的明文管理员密码，改为从当前 PowerShell 会话读取 `KONGZI_SMOKE_ADMIN_EMAIL` 与 `KONGZI_SMOKE_ADMIN_PASSWORD`；旧脚本中的测试密码应视为已泄露，如对应账号存在请立即轮换。
- 公共导航统一为“探索 / 学习 / 参与”三组，把案例、小测、术语等原先只在页脚/移动菜单出现的页面加入桌面一级菜单；页脚站点地图按同一分类列出所有公开入口。
- 移动端学习标签覆盖学习路径、读经、问答、小测和术语等子页；抽屉新增首页、个人中心与偏好设置入口，支持焦点限制、Esc 关闭、滚动锁定和安全区留白。
- 当前路由在顶部菜单、移动标签、抽屉和页脚统一高亮；导航文字、菜单辅助说明和无障碍标签加入五种语言词典。
- 游戏与案例中的“返回”链接采用统一的触控尺寸和二级视觉层级；首页的快捷链接增加点击高度，标题旁“查看更多”链接也有更清晰的焦点和悬停反馈。

## 首次启动

1. 将 `backend/.env.example` 复制为 `backend/.env`，并设置唯一的随机 `JWT_SECRET`（至少 32 字符）。不要复用仓库中的示例值。
2. 若启用 Neo4j，在 Compose 环境另外设置强 `NEO4J_PASSWORD`。
3. 全新安装在 `backend/` 目录运行 `python -m app.create_admin`，按提示输入邮箱和自己设置的密码，即可创建首个管理员；已有普通账号则运行 `python -m app.bootstrap_admin <邮箱>` 授予管理员权限。
4. 项目压缩包不包含本机数据库，也没有预置管理员账号或默认密码。之前提到的开发环境账号只在原开发数据库中有效，不能用于新解压的项目；这是截图中“邮箱或密码错误”的原因。请在新安装上创建自己的管理员凭据。密码只以哈希保存。
5. 管理员冒烟脚本运行前，在当前 PowerShell 会话设置 `KONGZI_SMOKE_ADMIN_EMAIL` 和 `KONGZI_SMOKE_ADMIN_PASSWORD`。不要把真实值写回脚本、源码或交付包。

## 尚未完成的产品能力

- `/quiz` 目前是六艺与读经入口，尚无独立题库、评分和错题复习。
- `/teach` 目前是教学工具入口，尚无班级/课程分配和学生报告。
- `/chat` 尚无可恢复的个人会话历史、服务端多轮上下文和角色设置；核验分数仍属演示指标。
- 账号密码找回/修改、完整的数据导出与账号删除关联数据策略仍需补齐。
- 游戏结算仍有服务端可验证性不足的情况；除聊天外的点赞/举报等公共互动也仍需统一频控和去重。
- 当前 `npm audit --omit=dev` 为 0 项；完整 `npm audit` 仍报告 9 项开发工具链告警（7 high、2 moderate），涉及 Tailwind 3 / ESLint 插件传递依赖。Tailwind 相关问题需要迁移到 Tailwind 4；`braces` 的上游公告暂时没有已发布的修复版本，因此不能靠锁文件更新消除全部告警。
